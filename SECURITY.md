# Security Policy

## Supported versions

CashLens is pre-alpha. Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Please report privately — **do not open a public issue**.

- Preferred: [GitHub Security Advisories](https://github.com/trh-ds/cashlens/security/advisories/new)
- Or email: <trhatwork@gmail.com>

Include steps to reproduce, affected component, and impact. Expect an acknowledgement within 7 days.

## Data handling

- Never include real bank statements, account numbers, GSTINs, PANs or other personal data in reports, issues or PRs.
- CashLens is not intended for production use with real third-party financial data.
- If you find real personal data committed to this repository, report it privately so it can be purged from history.
